# 困惑度

评估自回归语言模型时，在每个位置提供真实前文，看模型给实际下一个 token 分配多少概率。困惑度把这些位置的平均对数损失换回概率刻度，便于理解预测的难易程度。

## 从平均损失计算

令 $p_t$ 为第 t 个计分位置上实际 token 的预测概率，M 为计分位置数。用自然对数：

$$
L=-\frac1M\sum_{t=1}^{M}\ln p_t,\qquad
\mathrm{PPL}=e^L=\left(\prod_{t=1}^{M}p_t\right)^{-1/M}.
$$

因此，困惑度是这些概率的几何平均数的倒数。若使用以 2 为底的[[Concepts/信息论/交叉熵|交叉熵]]，则应计算 $2^L$。

例如两个位置的概率分别为 $1/2$ 和 $1/8$，乘积为 $1/16$，几何平均为 $1/4$，困惑度为 4。每个位置都面对四个等可能选项且答案在其中，也会得到 4。这种直觉不要求实际词表只有四项。[定义与计算条件](https://huggingface.co/docs/transformers/perplexity)

## 比较之前要对齐什么

分母数的是 token。更换[[Concepts/计算机基础/分词|分词]]方式后，同一文本可能变成不同数量的 token，逐 token 的困惑度随之改变了计量单位。

即使分词相同，也应对齐原文、上下文长度、特殊 token 与计分位置。长文本分段时，段首能看到多少前文会影响预测；使用重叠窗口时，同一个目标应只计分一次。汇总多个批次时，先加总损失，再除以有效 token 总数。

低困惑度说明模型给观测文本较高概率。要判断它是否更能解决某类任务，还应查看该任务的实际表现；可以按[[Concepts/研究方法/配对评测|配对评测]]保留同一批输入上的结果。
