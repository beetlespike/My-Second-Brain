# 哪些证据最后进了模型的回答？

设想一份报告先给结论，再写一个例外。问答系统要把两者都说清，得先搜到相应的段落，然后把它们送进模型，最后还得用对。

**搜到了什么？** [检索与重排](../Concepts/智能体与检索/Retrieval%20and%20Reranking.md)决定候选段落和排序。分别算候选集和最终选段的[检索召回率](../Concepts/模型评测/Retrieval%20Recall.md)，就能看出例外是没搜到，还是排得太靠后。如果一个问题需要汇总散落在许多报告里的线索，[GraphRAG](../Concepts/智能体与检索/GraphRAG.md)提供了按实体和关系组织材料的另一种办法。

**模型读到了什么？** [RAG](../Concepts/智能体与检索/RAG.md)把选中的段落放进提示词。[预填充](../Concepts/推理系统/Prefill%20and%20Decode.md)解释这些文字随后怎样被模型处理。要弄清增加输入会怎样影响首个 token 的等待时间，可以从这里走到[推理系统](推理系统.md)。

**还有什么没想清楚？** 假如相关段落都找到了，却没法全部装进输入，删哪一段会改变答案的意思？[检索上下文预算](../待学概念/智能体与检索/Retrieval%20Context%20Budget.md)里有一道可以自己算的题。即使选段合适，回答仍可能读错证据，这时可以转到[模型评测](模型评测.md)逐题比较。
