# 一个预测分布好不好，怎样衡量？

先区分三个对象：结果本身的概率分布、模型给出的预测，以及实际观测到了什么。

| 概念 | 回答的问题 | 接下来读什么 |
| --- | --- | --- |
| [信息熵](../Concepts/信息论/信息熵.md) | 结果出现之前有多不确定？ | 换成模型给出的概率，进入交叉熵 |
| [交叉熵](../Concepts/信息论/交叉熵.md) | 模型为实际发生的结果分配了多少概率？ | 与目标分布自身的熵比较，得到 KL |
| [KL散度](../Concepts/信息论/KL散度.md) | 用另一个分布描述结果，平均多付出多少对数损失？ | 检查两个分布的顺序与零概率 |
| [困惑度](../Concepts/信息论/困惑度.md) | 逐 token 的平均损失怎样换回容易理解的刻度？ | 核对分词、文本和计分条件 |

可以用同一组概率贯穿前三页：目标分布为 (0.75, 0.25)，预测为 (0.5, 0.5)。先计算熵与交叉熵，再用二者之差核对 KL。

比较语言模型的困惑度之前，需要知道每个 token 是什么。[[MOCs/文本编码与分词|文本编码与分词]]从字符开始解释这个单位。若要比较两种预测方法在同一批问题上的表现，可以转到[[MOCs/研究与实验|研究与实验]]。
