# 知识卡片与明确反馈

[English](Flashcard-Review.en.md)

卡片让人先回想，再对照解释。每张围绕一个具体问题，简答要能独立读懂，把必要的符号和条件交代清楚即可。题目里省下的推导和算例可以放在展开区。

复习卡保存在 `Flashcards/`，来源来自正式知识目录。另一种卡来自待学页（新库放在 `Study-Queue/`，完整示例和部分旧库放在 `待学概念/`），介绍关联的新概念。学习进度由你的解释、练习或确认决定。

## 一轮复习

1. 助手运行 `python3 .flashcards/review.py daily`，先逐条处理之前的留言。直接解答、订正原卡、补一道相关题都可以。把实际结果用 `resolve --input -` 记回知识库。
2. 待处理数归零后，用 `scan` 看新增或变动的来源，做卡、改卡。用 `audit` 核对格式、来源与可用性，再用 `daily --publish` 把题组送到本库固定的私人网页网址。可用 `--discovery <待学页>` 附上一个新概念。
3. 打开私人书签就能翻卡、评分。点术语可以看释义，在每条来源旁可以复制路径、用 Obsidian 打开原笔记，有节选时也可直接展开阅读。想提问时，可以直接写，也可以先点「例子没看懂」等快捷标签，再补充自己的问题。点保存后，评分用于安排复习，留言交给助手下次处理，也可以请它现在答复。「我的留言与回复」里可以回看题目、留言、答复，以及修订过的卡或关联卡。发卡时有作者署名的，这里也会显示。题目和答复中的公式支持离线显示。宿主支持 `--chat-output` 互动卡片时，聊天和网页共用同一份记录。

[每日任务与处理结果格式](../Prompts/每日复习.md)

默认每天最多 10 张复习卡，其中首次出现的最多 6 张，同一概念最多 2 张。可额外附一张新概念卡。没有可用或到期的复习卡时，工具跳过保存复习快照。同日重跑复用原来的复习卡。

“没想起来”“有点模糊”“比较熟悉”分别在收到评分后的 1、3、14 天重新进入候选。到期后优先安排，再按推送时间及主题轮换。每日上限可能延后实际出现时间。它们是可配置的固定间隔，尚未实现 FSRS，也没有据此验证学习效果。没有明确反馈时只轮换内容，个人掌握程度保持未知。

## 往期补看与当日改分

私人网页归档了两个不同日期的题组后，页首会显示 **往期 ▾**。选择日期，可以按当天最后一次实际发卡的顺序查看原题和原答案。来源链接打开的是现在的笔记。往期卡片可以继续留言，点「回到今日」可返回当前题组。

今天仍可评分的复习卡，可以先留言，稍后补评分。想改已保存的评分时，点「修改评分」，重新选择并保存。如果编辑期间另一个标签页先保存了评分，当前页会显示最新评分，清除这次冲突的选择。你写的留言和其他卡片的草稿会保留，可以再次提交。

往期仅接受留言（`past_issue`）。当卡片已改版（`superseded`），或卡片已移除、暂停、退役、来源待核对（`inactive`）时，也只能留言。同一版本若已在更新的一期评过分（`rated_newer_issue`），或你今天已在另一期给它评过分（`rated_other_today`），评分也会锁定。

## 新概念卡

新建的空白库和练习库都使用 `Study-Queue/`。可以把下面的小节保存到 `Study-Queue/相关抽样.md`，做成当天的探索卡。同一张卡的结构标题统一用中文或英文，正文可以用自己习惯的语言。

```markdown
## 知识卡

### 正面

每条记录复制一遍，样本均值的标准误会怎样变化？

### 简答

每次抽样的总和与行数都翻倍，均值的抽样分布保持相同，所以标准误也相同。
```

探索卡和复习卡都可以加上两三条必要的术语释义。在 `### 相关概念`（英文为 `### Key Terms`）下，每行写一条 `- 术语：简短解释`，读者点题面上的术语就能查看。要发布上面的探索卡，从新库根目录运行下面的命令。

```sh
python3 .flashcards/review.py daily --publish --discovery 'Study-Queue/相关抽样.md'
```

完整示例中的对应待学页是 `待学概念/数理基础/Correlated Sampling.md`。在完整示例或旧库中演练时，把命令中的路径换成该库里实际的待学页路径。打开私人网址即可查看这张卡、展开解释并单独留言。当天没有复习题也能收到它。待学卡只收文字反馈，读过或留言都不会改变熟悉度。

## 内容与版本

*（如果设了每日定时任务或让助手直接帮做卡，下面的结构与哈希均由助手自动生成并校验，无需手写。）*

每个卡片文件用 `type: flashcard_set`。每张卡以二级标题分隔，紧接一条 `<!-- card: {...} -->` 注释，记录 `id`、`version`、`status`、`concept`、`topic` 和 `sources`，还可以填写作者 `author`。术语释义可以写入注释的 `glossary` 字段，也可以写在术语小节，选一种即可。中文卡用 `### 正面`、`### 简答`，可选 `### 展开`、`### 来源` 和 `### 相关概念`。英文卡对应使用 `### Front`、`### Short Answer`、`### Details`、`### Sources` 和 `### Key Terms`。同一张卡的结构标题使用同一种语言。

ID 使用 `sb-fc-0001` 形式并保持稳定。status 为 active、paused 或 retired。每个来源有仓库相对 path、精确 heading 与该章节的 sha256。

以下命令可在下载的仓库根目录或完整示例副本中运行。先读「定义与条件」一节，确认它支持卡片，再计算指纹。

```sh
python3 .flashcards/review.py source-hash 'Concepts/数理基础/Standard Error.md' '定义与条件'
```

来源章节内容变化、章节消失或标题重复时，卡片会退出新题组。核对原文后，更新出处，必要时修订卡片。修改已注册卡片的题目、简答、展开、概念、主题或来源时，须递增 `version`。只改术语释义或 `author` 会保留卡片指纹和复习排期。`audit` 检查格式、来源指纹与可用性，注册卡片时（如 `session` 或 `daily --publish`）会核对版本。来源指纹用于发现本地文本变化，卡片里的结论仍须对照原文核实。

空白目录也可以使用下面的格式。选一个已经学过、已接入 Concepts 的章节，再换成自己的题目、答案和出处。用 `source-hash` 取得实际指纹，并在 Flashcards 目录中选择尚未使用的 ID。

```markdown
---
type: flashcard_set
status: active
---

# 相关抽样复习

## 重复观测

<!-- card: {"id":"sb-fc-0001","version":1,"status":"active","concept":"相关抽样","topic":"抽样估计","sources":[{"path":"Concepts/数理基础/Correlated Sampling.md","heading":"重复记录的计算","sha256":"替换为 source-hash 返回的完整值"}]} -->

### 正面

把每条独立观测复制成三条，均值的方差会变成原来的三分之一吗？

### 简答

设原来 m 个独立观测的方差都为 σ²。复制后，分子和分母都乘以三，均值仍是原来的均值，所以方差仍为 σ²/m。新增的行与原观测完全相关；误把 3m 行当成独立样本，才会得到 σ²/(3m)。

### 展开

$\bar X=3\sum_iY_i/(3m)=\sum_iY_i/m$。独立观测的数量仍是 m，复制只是重复记录。

### 来源

[相关抽样：重复记录的计算](../Concepts/数理基础/Correlated%20Sampling.md#重复记录的计算)
```

制卡后运行 `audit`，核对 `total`、`eligible`、`errors` 和 `needs_review`。写了一张卡却显示 `total: 0` 时，检查是否存到了 Flashcards，以及文件和元数据格式是否正确。来源待核对的卡片需要先处理，不能只改指纹来跳过检查。

本版示例的图谱节点使用英文文件名，原卡片 ID 保留，随来源路径改变的示例卡已更新版本。旧题组保留原内容和版本；查看旧题组时说明当前来源变化。旧版反馈只保留到历史，不直接调整新版间隔。退役卡保留历史。修订预览不生成新题组，也不接受评分。

## 反馈与保存

反馈按 `workspace_id`、`session_date`、`card_id` 和 `version` 对应到原库的题组和卡片。提交 `position` 时还会核对原题序号。重复提交按 `batch_id` 和卡片编号去重。私人网页保存评分时会附上 `expected_rating_sequence`，也就是开始编辑时看到的评分序号，首次评分用 `null`。序号过期时服务器返回 `409 Conflict`，整批反馈都需要重新提交。提交了无效卡片编号或版本也会整批回滚。

私人网页在当前浏览器保存草稿，重新打开同一知识库、同一期的同一版卡片时可以继续填写。已保存的评分与文字反馈以复习数据库为准。需要带走一份独立 HTML 时仍可运行 `session`，再用 `feedback --input <导出的文件>` 保存离线反馈。文字疑问单独保存，不自动转换为熟悉度。纠错先核查来源；同类问题可据实际反馈改进指南与其他卡片。

`daily` 按每次最多 20 条分页返回尚未处理的留言（有 `next_after` 时传入 `daily --after <编号>` 续读），包括旧版卡片与往期快照上的问题。一条具体答复、一次实际修订或一张相关卡都能作为处理结果。处理后可在留言下展开新版本或相关卡片。`notes` 可查最近 20 条文字记录。

.flashcards/local/review.sqlite3 保存版本、已发布期次、反馈与来源处理位置，属于需要备份的个人数据。生成界面可以重建。复制模板时不带出此目录；迁移自己的真实记录时应整体备份数据库，而非新建一份记录后混合导入。
