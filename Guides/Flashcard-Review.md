# 知识卡片与明确反馈

[English](Flashcard-Review.en.md)

卡片让人先回想，再对照解释。每张围绕一个具体问题，简答要能独立读懂，把必要的符号和条件交代清楚即可。题目里省下的推导和算例可以放在展开区。

复习卡保存在 `Flashcards/`，来源来自正式知识目录。另一种卡来自待学页（新库放在 `Study-Queue/`，完整示例和部分旧库放在 `待学概念/`），介绍关联的新概念。学习进度由你的解释、练习或确认决定。

## 一轮复习

1. 助手运行 `python3 .flashcards/review.py daily`，先逐条处理之前的留言。直接解答、订正原卡、补一道相关题都可以。把实际结果用 `resolve --input -` 记回知识库。
2. 待处理数归零后，用 `scan` 看新增或变动的来源，做卡、改卡。用 `audit` 核对格式、来源与可用性（修改内容时须递增 `version`），再用 `daily --publish` 把题组送到本库固定的私人网页网址。可用 `--discovery <待学页>` 附上一个新概念。
3. 你只需打开这个固定网址翻面、评分或提问（无需专门打开助手聊天框）。浏览器点保存就会直接写回知识库。评分用于排期，文字留给助手下一轮处理；需要马上答复时，也可以让它现在处理。「我的留言与回复」保留原问题、答复、修订卡与关联卡。如果桌面宿主启用了 `--chat-output` 聊天组件，两边共用同一份记录。

[每日任务与处理结果格式](../Prompts/每日复习.md)

默认每天最多 10 张复习卡，其中首次出现的最多 6 张，同一概念最多 2 张。可额外附一张新概念卡。没有可用或到期的复习卡时，工具跳过保存复习快照。同日重跑复用原来的复习卡。

“没想起来”“有点模糊”“比较熟悉”分别在收到评分后的 1、3、14 天重新进入候选。到期后优先安排，再按推送时间及主题轮换。每日上限可能延后实际出现时间。它们是可配置的固定间隔，尚未实现 FSRS，也没有据此验证学习效果。没有明确反馈时只轮换内容，个人掌握程度保持未知。

## 新概念卡

新建的空白库和练习库都使用 `Study-Queue/`。可以把下面的小节保存到 `Study-Queue/相关抽样.md`，做成当天的探索卡。同一张卡的结构标题统一用中文或英文，正文可以用自己习惯的语言。

```markdown
## 知识卡

### 正面

每条记录复制一遍，样本均值的标准误会怎样变化？

### 简答

每次抽样的总和与行数都翻倍，均值的抽样分布保持相同，所以标准误也相同。
```

从新库根目录运行下面的命令发布这张卡。

```sh
python3 .flashcards/review.py daily --publish --discovery 'Study-Queue/相关抽样.md'
```

完整示例中的对应待学页是 `待学概念/数理基础/Correlated Sampling.md`。在完整示例或旧库中演练时，把命令中的路径换成该库里实际的待学页路径。打开私人网址即可查看这张卡、展开解释并单独留言。当天没有复习题也能收到它。待学卡只收文字反馈，读过或留言都不会改变熟悉度。

## 内容与版本

*（如果设了每日定时任务或让助手直接帮做卡，下面的结构与哈希均由助手自动生成并校验，无需手写。）*

每个卡片文件用 `type: flashcard_set`。每张卡以二级标题分隔，紧接一条 `<!-- card: {...} -->` 元数据，记录 id、version、status、concept、topic、sources。题目和答案可使用中文三级标题（`### 正面`、`### 简答`、可选 `### 展开` 与 `### 来源`）或英文标题（`### Front`、`### Short Answer`、`### Details`、`### Sources`），同一张卡内请勿混用中英文小节名。

ID 使用 `sb-fc-0001` 形式并保持稳定。status 为 active、paused 或 retired。每个来源有仓库相对 path、精确 heading 与该章节的 sha256。

以下命令可在下载的仓库根目录或完整示例副本中运行。先读「定义与条件」一节，确认它支持卡片，再计算指纹。

```sh
python3 .flashcards/review.py source-hash 'Concepts/数理基础/Standard Error.md' '定义与条件'
```

来源变化、消失或标题不唯一时，卡片退出新题组。核查后更新文字、来源指纹和版本。指纹只能发现文本变化，不能核验科学正确性或远程原文是否更新。`audit` 核对卡片格式、来源哈希与可用性；修改已注册卡片正文或来源却未升版本时，工具会在注册卡片时拒绝。

空白目录也可以使用下面的格式。选一个已经学过、已接入 Concepts 的章节，再换成自己的题目、答案和出处。用 `source-hash` 取得实际指纹，并在 Flashcards 目录中选择尚未使用的 ID。

```markdown
---
type: flashcard_set
status: active
---

# 相关抽样复习

## 重复观测

<!-- card: {"id":"sb-fc-0001","version":1,"status":"active","concept":"相关抽样","topic":"抽样估计","sources":[{"path":"Concepts/数理基础/Correlated Sampling.md","heading":"重复记录的计算","sha256":"替换为 source-hash 返回的完整值"}]} -->

### 正面

把每条独立观测复制成三条，均值的方差会变成原来的三分之一吗？

### 简答

设原来 m 个独立观测的方差都为 σ²。复制后，分子和分母都乘以三，均值仍是原来的均值，所以方差仍为 σ²/m。新增的行与原观测完全相关；误把 3m 行当成独立样本，才会得到 σ²/(3m)。

### 展开

$\bar X=3\sum_iY_i/(3m)=\sum_iY_i/m$。独立观测的数量仍是 m，复制只是重复记录。

### 来源

[相关抽样：重复记录的计算](../Concepts/数理基础/Correlated%20Sampling.md#重复记录的计算)
```

制卡后运行 `audit`，核对 `total`、`eligible`、`errors` 和 `needs_review`。写了一张卡却显示 `total: 0` 时，检查是否存到了 Flashcards，以及文件和元数据格式是否正确。来源待核对的卡片需要先处理，不能只改指纹来跳过检查。

本版示例的图谱节点使用英文文件名，原卡片 ID 保留，随来源路径改变的示例卡已更新版本。旧题组保留原内容和版本；查看旧题组时说明当前来源变化。旧版反馈只保留到历史，不直接调整新版间隔。退役卡保留历史。修订预览不生成新题组，也不接受评分。

## 反馈与保存

反馈必须绑定原题组的 workspace_id、session_date、card_id 和 version；如提交了 position，工具也会核对原题序号。重复提交按 batch_id 和卡片编号去重，整批有非法编号或版本时回滚。不同学习目录的反馈不能混用。

翻面或关闭页面时，草稿尽量留在原浏览器。已保存的评分与文字反馈以复习数据库为准。需要带走一份独立 HTML 时仍可运行 `session`，再用 `feedback --input <导出的文件>` 保存离线反馈。文字疑问单独保存，不自动转换为熟悉度。纠错先核查来源；同类问题可据实际反馈改进指南与其他卡片。

`daily` 按每次最多 20 条分页返回尚未处理的留言（有 `next_after` 时传入 `daily --after <编号>` 续读），包括旧版卡片上的问题。一条具体答复、一次实际修订或一张相关卡都能作为处理结果。处理后可在留言下展开新版本或相关卡片。当天已经发出的题组保留当时的内容。查最近 20 条文字记录可用 `notes`，定时任务用 `daily` 取待办。

.flashcards/local/review.sqlite3 保存版本、快照、反馈与来源处理位置，属于需要备份的个人数据。生成界面可以重建。复制模板时不带出此目录；迁移自己的真实记录时应整体备份数据库，而非新建一份记录后混合导入。
