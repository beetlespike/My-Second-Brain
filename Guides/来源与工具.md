# 材料怎么读，用什么工具

[English](Sources-and-tools.md)

在学习库打开你使用的 AI 助手聊天窗口，直接贴链接就行。手机复制的分享文字可以带标题，读取器一次认一个网址。也可以在库目录运行下面的命令，查看读到了什么、正文存在哪里。

```sh
python3 tools/intake.py 'https://arxiv.org/abs/2309.06180'
```

| 来源 | 随库读取器会做什么 | 还可以用什么 |
| --- | --- | --- |
| B 站、YouTube | 调用 yt-dlp 选取本集的字幕，保留起止时间，区分平台字幕和自动字幕。缺字幕时，已有本地转写环境和模型可处理公开音轨。 | 发布方提供的同集字幕、安装好的视频工具、浏览器中的逐字稿或自己的 SRT/VTT。弹幕、简介和课程讲义另计。 |
| 公众号、文章 | 公众号读原站的 `js_content` 正文。普通网页取文章或主内容区域。配图需要单独查看。 | 原页只显示验证提示时，可用已授权的浏览器读原文，交给读取器保存的 HTML 或正文。 |
| 论文 | 优先用指定的已有解析。arXiv 摘要页先取同版本 HTML 正文，再试 PDF 文字层。直接给 PDF 链接则先读 PDF。期刊和会议页可读明确标记的论文 PDF。只有摘要时会标为摘要。 | 已有 MinerU 或 Docling Markdown、公开 PDF、扫描件的 OCR 文本。核对重要图表和公式时看原页。 |
| 学习对话、书籍、实践 | 直接读选定的 Markdown 或文本文件。 | 对话历史由宿主提供，见[自动整理](自动整理与维护.md)。章节、实验记录和聊天的 Markdown 或文本导出可以直接读取。 |

**仓库提供** [读取器](../tools/intake.py)、[整理提示](../Prompts/整理材料.md)、知识库检查和复习工具。读取器整理证据，你的 AI 助手负责读证据、写资料笔记、提炼概念并检查同义页。材料内容和个人掌握程度分别记录。

### 接回已有的文件

```sh
python3 tools/intake.py lesson.vtt
python3 tools/intake.py 'https://arxiv.org/abs/2309.06180' --from paper/full.md
```

`--from` 保留原链接，并读取指定文件。字幕或正文用 UTF-8，或带字节顺序标记（BOM）的 UTF-16 均可。解析目录里只有一份 Markdown 时也可直接给目录。视频可以指定发布方的字幕 URL，或含同一视频标识和字幕轨的公开课程页。若手头只有摘录或摘要，使用 `--scope excerpt` 或 `--scope abstract` 说明范围。

要长期复用已有文件，可在自己库的 `.local/source-files.json` 中，把原链接对应到已有解析。相对路径从这个配置文件所在目录算起。这项可选设置也适用于已有字幕或文章导出。

```json
{"https://arxiv.org/abs/2309.06180": "parses/pagedattention/full.md"}
```

### 按需安装

网页和已有文本用 Python 3.9 或以上的标准库即可。读 PDF 文字层需要 Poppler 的 `pdftotext`。在线视频字幕用 [yt-dlp](https://github.com/yt-dlp/yt-dlp#dependencies)。想用下面的 pip 命令安装它，请用 Python 3.11 或更新版本。

```sh
python3 -m venv .venv
.venv/bin/python -m pip install yt-dlp
```

Windows 对应的解释器是 `.venv\Scripts\python.exe`。读取器能找到 PATH、当前 Python 或本库 `.venv` 中的工具，也能复用已有的本地转写运行环境。

需要语音转写时，在同一虚拟环境安装 [faster-whisper](https://github.com/SYSTRAN/faster-whisper)，准备一份本地模型。已有环境和权重可直接复用。可用 `--asr-model` 指定模型目录，或用 `--no-asr` 只找字幕。工具也识别常规缓存中已安装的 small 模型。另一个环境里的可执行文件可用 `MSB_YTDLP`、`MSB_VIDEO_PYTHON` 或 `MSB_ASR_MODEL` 指定。登录后的页面由你已授权的浏览器读取。

### 看结果

`ready` 表示有文本可用于整理，`evidence` 说明是字幕、转写、网页正文还是 PDF 文字层。`partial` 返回已读部分。`needs_network` 表示终端网络受限，助手应先通过宿主的联网审批重试。`needs_material` 会说明还缺什么。这三种情况的退出码均为 2。你的 AI 助手会先试可用的其他读取方式，最后才向你要缺的那一份。原文和读取记录存在 `.local/imports/`。同一链接可复用，`--refresh` 重新读取。个人缓存与反馈不会随模板复制。
