# 第一次使用

[English](First-Run.md)

## 自己的学习库

在下载的模板目录运行下面的命令，就能在旁边建一个带工具和指南的空白目录。自己的笔记写到这个新目录里。公开 fork 里提交并推送的笔记也会公开。

```sh
python3 tools/workflow.py init ../My-Learning --empty
```

推荐用 Obsidian 阅读、用 Codex 整理。也可以用自己的编辑器和能读写本地文件的 AI 助手。完整示例在模板里。命令需要 Python 3.9 或更新版本，在 Windows PowerShell 里可用 `py -3` 代替 `python3`。

## 今日知识卡

第一次，让能运行本地命令的助手“打开今日知识卡”，或双击库目录里的 `Today.command`（macOS）、`Today.cmd`（Windows）。Linux 可用 `sh Today.command`。收藏打开的私人网址。以后每天用这个书签，电脑重启后再运行一次入口，地址照旧。

复习卡可以评分，也可以只写疑问。待学卡可以展开简答，在卡片下留言。点保存就会写回知识库。想每天收到新题，给自己的助手设一个[每日任务](自动整理与维护.md)。它先处理上次留下的问题，再做卡、更新题组。回答和改过的卡都在「我的留言与回复」里。用 Codex 的人也可以在定时聊天里翻卡、提交反馈。

## 从一份材料开始

看完视频或读完文章后，把网址交给能读写这个库的助手。它会读取材料、提炼概念、找出能接上的旧笔记。想只留某一段，可以顺手提一句。字幕、正文和 PDF 也能直接交给它。

换一份材料时沿用同一张网。几个概念可以一起回答一个问题时，助手会把它们编成主题地图（MOC），你可以从图上打开相关笔记。换用其他 Markdown 编辑器、能读本地文件的助手或自己的材料读取工具也可以。[来源与读取工具](来源与工具.md)

## 走一遍推理服务的例子

完整模板里可以直接打开 `MOCs/Streaming LLM Serving.md`。要从材料自己推一遍，在模板目录运行下面的命令，再打开新目录。

```sh
python3 tools/workflow.py init ../My-Learning-Trial --demo
```

1. 从 `assets/demo/serving-sources.md` 选一份材料，学过感兴趣的部分后，把来源链接贴给 Codex。离线也可以先读练习字幕 `assets/demo/first-token.vtt`，再把文件交给它。顺着生成的资料笔记读一页概念。
2. 学过第二份材料后，也把它交给 Codex。用本地字幕开始的话，可以接着读 `assets/demo/streaming-dialogue.md`。Codex 能把对话里「等多久才见到第一个 token」的问题，连回字幕里的预填充，再把能一起解释这个问题的笔记编成主题地图。
3. 让 Codex 顺着已有联系找出尚未收录的概念。示例的三个候选分别涉及批内干扰、服务达标率和两阶段拆分。挑一个，先做它的卡。若能解释自己的判断，再把概念接回正式网络并生成复习题。
4. 想沿着拆分的例子继续，材料清单里有 *DistServe* 的原文。带着卡片上的问题去读一段，再把论文链接交给 Codex，看看这次阅读给原来的概念添了什么。

在**完整示例库**里，可以让助手打开今天的卡片，附上「预填充与解码分离」。助手也可以直接运行下面的命令。从自己的材料开始时，使用自己库里的待学笔记。

```sh
python3 .flashcards/review.py daily --publish --prefer-new sb-fc-0015 --discovery '待学概念/推理系统/Prefill-Decode Disaggregation.md'
```

想看看反馈如何改变一张卡，可以在卡片下留一句具体的问题。助手处理后，回到同一网址就能看答复。[每日卡片与自动化](自动整理与维护.md) · [学习记录与反馈](Flashcard-Review.md)
