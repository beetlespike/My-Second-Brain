# 第一次使用

[English](First-Run.md)

可以从自己的材料开始，也可以用仓库里的示例。下面的提示供你改写；已经有概念笔记时，可以直接从回顾或复习开始。

## 整理一份材料

让 Obsidian 和 Codex 打开同一个目录，给 Codex 链接、正文、PDF、字幕或选定对话，再说清想弄懂的问题：

> 请按 AGENTS.md 整理这份材料。我想理解……把有关概念补进已有网络，保留出处，并指出值得继续学的问题。

完成后，从 `MOCs/知识库入口.md` 看资料与概念怎样相连。同一概念再次出现时，通常补充原页即可。读不到的正文、附件或画面应说明范围；可选读取工具见[来源与工具](来源与工具.md)。

想先试现成材料，可以使用 `assets/demo/文章原文.md` 和 `assets/demo/教学字幕.vtt`。它们共同涉及样本均值、标准误与样本量，适合观察两个来源怎样共享概念。

## 选一个问题继续学

整理时可能已经有了待学建议，也可以主动回顾：

> 看看这些概念之间还缺哪一步解释，给我一个有依据、能直接开始学的建议，说明它连接了哪些已有内容。

比如这组统计材料提到了独立抽样，可以接着问“观测相关时会怎样”。有了感兴趣的待学页，就让 Codex 从例子、推导或问答开始，按你习惯的方式展开。做一道变式有助于检查理解；卡住时直接指出那一步。

你自己的解释和应用可以作为学习进展，AI 生成的答案不能代替。理解后可接回正式概念网络，更新原有链接，并把值得记住的问题做成卡片。

## 复习与反馈

> 请按 Prompts/每日复习.md，为这些学过的内容准备卡片，核对来源后给我可在浏览器打开的复习页面。

在页面里先回想、再翻面。可以选择熟悉程度或写下疑问，点击“导出反馈文件”，把下载的 JSON 交给 Codex 保存。看到实际保存结果后，反馈才会影响后续安排；重复导入会去重。

当天题组会保留原内容，同日重跑仍是同一组，之后新增的卡片由后续题组安排。首次体验时，可以先完成学习和制卡再生成题组。[卡片指南](Flashcard-Review.md)里有完整格式和说明。

## 按自己的习惯调整

想单独建立自己的库，可以让 Codex 在项目旁边初始化一份空白目录；试用合成材料时再复制所需的两份原文。目录名字、资料类型和提示都可以调整，初始化命令见[工具与扩展](工具与扩展.md)。用顺手后，再考虑[定期整理](自动整理与维护.md)。
