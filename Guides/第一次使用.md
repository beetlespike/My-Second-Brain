# 第一次使用

[English](First-Run.md)

### 从学过的东西开始

用 Obsidian 和 Codex 打开同一个学习目录。选一段自己能讲出点门道的材料，告诉 Codex 你理解了什么。可以这样开头。

> 我读完了这部分。我的理解是……。请把这里的几个概念分别写清楚，找找库里哪些概念跟它们有关系，在链接旁写一句为什么。同一个概念已有笔记的话，补进去。

换一份材料时沿用同一张网。等几个概念可以一起回答一个更大的问题，就把它们写进一张主题地图（MOC）。换用其他 Markdown 编辑器、能读本地文件的助手或自己的材料读取工具也可以。[来源与读取工具](来源与工具.md)

### 走一遍推理服务的例子

完整模板里可以直接打开 `MOCs/Streaming LLM Serving.md`。要从材料自己推一遍，在模板目录运行下面的命令，再打开新目录。要建自己的空白库，把 `--demo` 换成 `--empty`。

```sh
python3 tools/workflow.py init ../My-Learning-Trial --demo
```

1. 打开 `assets/demo/serving-sources.md`，里面有一段 B 站视频、一篇公众号文章、一篇有英文报告的系统论文和一段改写对话。挑你读懂的部分开始。例如先解释为什么解码能复用 KV，再算对话里的四个 token 平均等了多久。
2. 在另一份材料中找一个能接上来的概念。长提示进批时，老请求要等下一轮。请 Codex 把这个关系写到「连续合批」和「分块预填充」之间。从「为什么会卡」这个问题整理一张主题地图。
3. 让 Codex 顺着已有联系找出尚未收录的概念。示例的三个候选分别涉及批内干扰、服务达标率和两阶段拆分。挑一个，先做它的卡。若能解释自己的判断，再把概念接回正式网络并生成复习题。

在**完整示例库**里，下列命令可以直接打开这条学习路径。它会生成包含新概念和复习题的本地 HTML，文件位置见输出的 `output`。从空白目录开始时，换成自己实际建好的待学笔记。

```sh
python3 .flashcards/review.py session --prefer-new sb-fc-0015 --discovery '待学概念/推理系统/Prefill-Decode Disaggregation.md'
```

翻到复习卡背面，可以选熟悉程度，也可以展开「补充反馈或指出问题」留一句意见。在浏览器里点「导出反馈文件」，交给 Codex 导入。评分用来排下次复习，你也可以请它按留言改题。[每日卡片与自动化](自动整理与维护.md) · [学习记录与反馈](Flashcard-Review.md)
