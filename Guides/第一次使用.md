# 第一次使用

[English](First-Run.md)

## 自己的学习库

在下载下来的模板目录里运行下面的命令，就能在旁边建一个只含工具、提示词和指南的干净私人库——没有需要手动清理的作者示例（需要 Python 3.9+，Windows PowerShell 可用 `py -3`）。公开 fork 里提交并推送的笔记也会公开。

```sh
python3 tools/workflow.py init ../My-Learning --empty
```

新库备好了知识索引，里面没有示例学习笔记或现成卡片。可以用熟悉的 Markdown 编辑器打开，再给助手读写文件和运行本机命令的权限。项目规则在 `AGENTS.md` 里，Claude Code 通过 `CLAUDE.md` 导入同一份规则。

## 从你学过的第一份材料开始

1. **交出一份你刚学过的真实材料**：看完一个视频、读完一篇文章或论文，或者刚在一段 AI 对话里把一个问题聊透，把链接或保存的记录发给新目录里的 AI 助手；有特定关心的时间段、章节或想法，可以顺手附一句。字幕、纯文本和 PDF 都能直接交过去。
2. **对照自己的实际理解把关**：助手会把提炼出的概念写进 `Concepts/`，用正常的话写清两条概念为什么相连并加上标准相对路径链接，同时在 `Videos/`、`Articles/`、`Papers/` 或 `Chats/` 记下出处。还没真正弄懂的地方直接删改，确保这个库永远映射你真实掌握的知识。
3. **接进第二份材料，长出地图**：继续投喂同一方向的新材料后，助手会把相关概念跨材料连起来，把能共同回答一个问题的几页编成 `MOCs/` 主题地图；发现还差一层拼图时，也会在 `待学概念/` 里提出可继续深挖的候选页。[来源与读取工具](来源与工具.md)

## 今日知识卡

当 `Concepts/` 里攒下学过的概念后，可以让助手在 `Flashcards/` 帮你做出第一批复习卡。接着运行库目录里的 `Today.command`（macOS）、`sh Today.command`（Linux）或 `Today.cmd`（Windows）——或让能运行本机命令的助手“打开今日知识卡”——就能拿到固定的本机私人网址。收藏这个网址，电脑重启后再运行一次启动器，原书签依然有效。

卡片页面右上支持切换 **EN / 中文**（或通过 `?lang=en` / `?lang=zh` 指定）。翻开复习卡可以自评记忆熟悉度或写下疑问；点**保存**后会直接写回知识库并当场计入本地排期（旧版卡片各自的评分记录留在历史里）。待学卡可以展开查看解释，并在下方留言。想按节奏自动更新题组，可为助手设置[每日任务](自动整理与维护.md)：它每次都会先处理积压的留言——可直接答疑、修订卡片，或另附一张相关卡——再发布当天题组，处理结果全部留在「我的留言与回复」里。若你使用的聊天宿主支持内嵌交互卡（例如 Codex 定时聊天），也可以在对话里同步翻卡和提交反馈。

## 逛逛成品示例库

如果你动手建库前只是想先翻翻成品长什么样，直接看现在这个模板目录就行，不用自己从原始材料重推一遍示例：

- 用任意编辑器（或 Obsidian）直接打开 `MOCs/Streaming LLM Serving.md`，看跨媒介、跨语言的笔记怎样连成网。
- 想直接翻看示例卡，可以在模板目录里打开 `Today.command`（macOS）、运行 `sh Today.command`（Linux），或打开 `Today.cmd`（Windows）。首组会从 15 张示例卡里选出 6 张。
- 想看截图里的那一组，请在一份全新示例中，**首次打开卡片之前**运行下面的命令。打开返回的私人网址，就能看到待学卡和下方的 TPOT 复习题。当天再次打开时会沿用已有复习题组。

```sh
python3 .flashcards/review.py daily --publish --prefer-new sb-fc-0015 --discovery '待学概念/推理系统/Prefill-Decode Disaggregation.md'
```
