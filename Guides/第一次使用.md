# 第一次使用

[English](First-Run.md)

把同一个文件夹打开为 Obsidian 库和 Codex 项目。你可以拿自己的材料直接试，也可以用下面两份合成材料。想给自己的笔记另建一个空白库，可以把命令中的 `--demo` 换成 `--empty`。

## 用两份原文试一次

让 Codex 在下载并解压的模板目录运行，或用 Python 3.9 以上自己运行：

```sh
python3 tools/workflow.py init ../My-Learning-Trial --demo
```

在 Obsidian 和 Codex 中切换到新建的 `My-Learning-Trial`。里面有字幕和短文，概念页和卡片由你和 Codex 接下来一起整理。目录已存在时，选个新名字即可。

1. 先交给 Codex `assets/demo/教学字幕.vtt`，问它：“按 AGENTS.md 帮我弄清为什么独立抽样时，样本越多，样本均值的波动越小。把推导写进概念页，并留好时间戳。”在知识库入口打开它整理的笔记。
2. 再给它 `assets/demo/文章原文.md`：“这篇解释和字幕里的哪些内容共用一个概念？把它补进原页，保留两份出处。”打开「标准误」，你应该能找到视频的推导和文章对波动的解释。
3. 问：“这几篇概念页都用了什么条件？如果条件不成立，有没有一个值得接着学的问题？”确认待学建议能回到相关笔记。用自己的材料时，可以换成任何一个令你好奇的联系。

## 学下去，再做一张卡

选一个建议，请 Codex 从例子或一道题开始。这里可以问：“把每条观测原样复制一遍，标准误会改变吗？先让我说说理由。”觉得哪里跳得太快，就从那一步展开。如果没聊完，让它在待学页留下你已弄清的部分和下次要问的问题。

当你能用自己的话解释，或明确告诉 Codex 这部分已学会，可以让它把概念接回正式网络，更新原来的链接。接着试一次复习：

> 按 Prompts/每日复习.md 把刚学的内容做成一张卡，核对来源后给我可以在浏览器打开的复习页面。

先回想，再翻卡。可以选熟悉程度，或在「补充反馈或指出问题」写下疑问。点「导出反馈文件」，把 JSON 交给 Codex 导入。看到工具报告保存成功后，下次可以让 Codex 找回卡片原来的题目、疑问和来源。当天已有的题组会原样保留，之后新增的卡片由后续题组安排。[卡片格式与反馈](Flashcard-Review.md)

## 换成自己的材料

把练习里的字幕和文章换成你实际看过的内容，先说清想解决的问题。已经有笔记时，可以直接从回顾或复习开始。其他编辑器可用相对路径的 Markdown 链接，其他有文件权限的助手也可按同样方式工作。需要增加来源或调整复习节奏时，可从下面的指南开始。
