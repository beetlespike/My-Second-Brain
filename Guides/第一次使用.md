# 第一次使用

[English](First-Run.md)

## 自己的学习库

在克隆下来的模板目录里运行下面的命令，就能在旁边建一个只含工具、双语提示词与指南的干净私人库——零作者示例、拿来即用：

```sh
python3 tools/workflow.py init ../My-Learning --empty
```

*（需要 Python 3.9+，Windows PowerShell 可用 `py -3`。公开 fork 里提交并推送的笔记也会公开。）*

用 `--empty` 建出的目录自带中英文索引页（`MOCs/知识库入口.md` 与 `MOCs/Knowledge-Index.md`），起步为 `0` 篇示例笔记、`0` 张卡片。用任意 Markdown 编辑器都能打开（想逛知识图谱时再用 Obsidian），让能读写文件、执行本地命令的 AI 助手打开这个目录即可：**Codex、Cursor、Antigravity** 直接读取根目录 `AGENTS.md`（中文完整对照见 `AGENTS.zh.md`），**Claude Code** 通过 `CLAUDE.md` 自动导入同一份规则。

## 从你学过的第一份材料开始

1. **交出一份你刚学过的真实材料**：看完视频、读完文章或论文，或刚在 AI 对话里把一个问题聊透，把链接或保存的文件发给新目录里的助手；有特别关心的时段、章节或想法，顺手带一句。字幕、纯文本与 PDF 都能吃（网页文章只需 Python 3.9+；在线视频字幕需 `yt-dlp`，PDF 提纯需 `pdftotext`）。
2. **只把真正弄懂的部分留下来**：助手会按[整理材料提示词](../Prompts/整理材料.md)把概念写进 `Concepts/`，用标准相对路径链接解释两处概念为什么相通，并在 `Videos/`、`Articles/`、`Papers/` 或 `Chats/` 记下出处。还没消化的地方直接删改，保持库里永远是你自己知识网的真实映射。
3. **接进第二份材料，让缺口浮出来**：继续贴入同一领域的另一份材料，助手就会跨出处串联概念、把能共同回答一个问题的几页编成 `MOCs/` 主题地图，并把顺着联系自主发现的候选概念先存进 `待学概念/`（英文目录支持 `Study-Queue/`）。[来源与读取工具](来源与工具.md)

## 今日知识卡

你完全**不用手写卡片格式或手动排期**。每个知识库所有复习卡和提问都收敛在**一个固定的私人本机网页书签**里，一次收藏、每天复用：

1. **配好一次每日任务。** 按[自动化指南](自动整理与维护.md)选定时间，之后平时只管贴学过的链接。助手出卡前会先处理上次的留言，根据新学内容做复习卡，发现值得补学的关联概念时再加上一张定制探索卡。收藏它返回的私人网页，以后每天打开同一个书签。
2. **还没设自动任务，想先跑一次试试**：直接对目录里的助手说一句：
   > 根据我刚才整理出来的几个概念帮我做几张复习卡，检查没问题后打开今日知识卡。
   助手会完成制卡、校验并印出本库的固定私人网址，在浏览器打开存书签即可。

本机服务开着时，直接点书签就能看卡。想自己启动服务时（例如电脑重启后），macOS 双击 `Today.command`，Linux 运行 `sh Today.command`，Windows 双击 `Today.cmd`，打开的仍是同一个网页。

网页右上支持切换 **EN / 中文**（或 URL 带 `?lang=en` / `?lang=zh`）。翻开复习卡可评分熟悉度或提问；点**保存**后立即写回 SQLite 数据库并计入排期（旧版卡片评分各自留在历史）。待学探索卡可展开查看解释并在下方留言；助手给出的答复、修过的卡或关联卡片，下次都会出现在「我的留言与回复」里。

## 逛逛成品示例库

想逛成品，用编辑器或 Obsidian 直接打开下载目录里的 `examples/demo-vault/`，从 `MOCs/知识库入口.md` 开始看。想先翻卡，打开**仓库根目录**的启动器，首次题组会从 15 张示例卡中选出 6 张。

如果想看到截图里的 TPOT 复习题和「预填充与解码分离」探索卡，请从下载的仓库目录运行下面的命令。它会建立一个独立示例副本，再发布这组卡片。打开返回的私人网址即可。请在副本中第一次打开卡片之前发布，当天后续打开会沿用第一次选好的复习题。

```sh
python3 tools/workflow.py init ../My-Demo
cd ../My-Demo
python3 .flashcards/review.py daily --publish --prefer-new sb-fc-0015 --discovery '待学概念/推理系统/Prefill-Decode Disaggregation.md'
```
