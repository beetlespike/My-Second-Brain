# 工具与扩展

[English](Tools-and-Extensions.md)

能运行本地命令的 AI 助手可以代办下面的操作。离线复习用 Python 3.9 或以上和随库的 KaTeX。命令从学习目录运行，在 Windows PowerShell 里可用 `py -3` 代替 `python3`。

## 常用命令

在已有项目旁边创建空白学习目录：

```sh
python3 tools/workflow.py init ../My-Learning --empty
```

从完整模板运行时，可以把 `--empty` 换成 `--demo`，只带原始演示来源文件。省略这两个选项会复制当前示例知识，包括配置过的来源目录。个人复习记录、缓存、Obsidian 设置与 Git 历史不随模板复制。

检查与复习：

```sh
python3 tools/workflow.py check
python3 .flashcards/review.py audit
python3 .flashcards/review.py scan
python3 .flashcards/review.py today --no-open
python3 .flashcards/review.py daily
```

双击库里的 `Today.command`（macOS）或 `Today.cmd`（Windows）会启动本机（`127.0.0.1`）服务并用浏览器打开这个库的固定私人网址（Linux 可用 `sh Today.command`），通常只在首次打开或电脑重启后未开助手聊天时用一次。`today --no-open` 返回同一地址，`today --stop` 可关闭后台服务。

每日任务先运行 `daily`，把尚未办完的留言逐条答复或修卡，用 `resolve --input -` 写回处理结果。接下来做卡、更新，再用 `daily --publish` 发布到私人网址。用 `--discovery <待学页路径>` 可以附一张新概念卡（兼容 `待学概念/` 与 `Study-Queue/`）。需要在支持交互组件的聊天里也展示时，加 `--chat-output <路径>`。[卡片格式](Flashcard-Review.md) · [每日任务](自动整理与维护.md)

浏览器的保存按钮直接写入知识库。聊天助手用 `feedback --input -` 保存用户主动提交的反馈。`notes` 可查看最近 20 条文字记录，`show --date YYYY-MM-DD` 可查看历史题组。需要带走单个离线文件时，`session` 可以生成独立页面。`--root` 和 `--state-dir` 在子命令前指定知识库及其独立记录目录。

`check` 检查本地链接、wikilink 章节、资料类型与来源属性，属性只读取简单标量字段。远程网页和知识结论需要另行核对。`audit` 检查卡片格式、来源指纹与可用性，来源变化会列入 `needs_review`；读完变化并核对卡片后，再更新指纹与版本。

下载的框架把示例单独放在 `examples/demo-vault/`。从框架根目录运行 `python3 tools/workflow.py --root <知识库> check` 可检查另一座库，用 `python3 .flashcards/review.py --root <知识库> audit` 可核验那座库的卡片。初始化出来的个人库自带工具，复习记录存于本机。升级已有框架副本后，运行一次启动器即可沿用示例原有的复习数据库和书签。

## 少量设置

新模板按电脑的本地日期发卡。若旅行时也想按家里的日期复习，可将 `.secondbrain.json` 的 `timezone` 从 `local` 改为 `Asia/Shanghai` 等时区名。系统缺少命名时区数据时，在使用的 Python 环境中安装 `tzdata`。

`.secondbrain.json` 还可设置 `daily_limit`、`new_limit`、`concept_limit`、`interval_days` 与 `source_dirs`。每日上限 1–25，新卡上限可以为 0。修改设置只影响后续选卡。

`source_dirs` 列出正式知识的顶层目录。例如想保存实践记录，可建立 `Practice/`，把 `"Practice"` 加进列表，再给笔记标注 `type: practice`、来源和证据状态。工具会递归检查该目录，引用其中的章节制卡时也能核对原文。待学目录（`待学概念` / `Study-Queue`）与 `Flashcards` 不可加入制卡来源。[其他来源](其他来源.md)

目录层次可以按领域调整。统一使用标准相对路径 Markdown 链接，例如 `[标准误](../Concepts/数理基础/Standard%20Error.md)`，各类编辑器与图谱工具均可识别。修改卡片引用的标题或路径时，也要更新对应来源和版本。

## 按需扩展

随库的 `tools/intake.py` 可直接读材料链接或本地文件。具体用法和可选工具见[来源与工具](来源与工具.md)，也可以沿用你已有的工具或直接提供文本。定期整理对话、回顾概念和维护公开仓库的做法见[自动整理与维护](自动整理与维护.md)。

复习使用三档固定间隔。若以后接入 FSRS 等排程算法，需保留卡片编号、内容版本、明确反馈和历史题组，并验证评分映射与排程变化。

## 接入已有库

已有的 Markdown 笔记可以继续放在原处。先用整理提示把同一主题的来源和概念连起来。要接入卡片工具，可以把模板 `.flashcards/` 中的程序文件复制到已有库，个人记录目录 `local/` 留在原库，按上一节把知识正文目录填进 `.secondbrain.json` 的 `source_dirs`。如果那里已有同名文件，逐项合并。卡片放进 `Flashcards/`，新库的待学页放在 `Study-Queue/`，已有库可以沿用 `待学概念/`，格式支持中文或英文小节标题，见[卡片指南](Flashcard-Review.md)。使用 Git 时，可将 `.flashcards/local/` 和 `.local/` 加入忽略列表，复习数据保留在本机。

## 检查代码改动

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s .flashcards -p 'test_*.py'
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tools -p 'test_*.py'
```

测试使用通用示例与独立临时目录。修改界面后，在普通浏览器检查翻面、展开、来源、反馈导出、重新打开与窄屏。

有 Node.js、Playwright 和 Chromium 时，可用 `node tools/test_chat_feedback.cjs` 检查分次提交和断线重试。测试在临时知识库保存反馈。
