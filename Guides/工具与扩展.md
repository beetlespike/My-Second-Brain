# 工具与扩展

可以把下面的操作交给 Codex，也可以自己运行。需要 Python 3.9 或以上，使用标准库和随附的 KaTeX，支持离线复习。所有命令从学习目录运行。Windows 可以将 `python3` 换为 `py -3`；系统缺少时区数据时，在项目虚拟环境安装 `tzdata`。

## 常用命令

在已有项目旁边创建空白学习目录：

```sh
python3 tools/workflow.py init ../My-Learning --empty
```

省略 `--empty` 会带上当前知识，包括配置过的来源目录。两种方式都保留指南、工具和许可证。目标目录需要为空；个人复习记录、缓存、Obsidian 设置与 Git 历史不随模板复制。

检查与复习：

```sh
python3 tools/workflow.py check
python3 .flashcards/review.py audit
python3 .flashcards/review.py scan
python3 .flashcards/review.py session
python3 .flashcards/review.py feedback --input '下载的反馈.json'
```

反馈也可以直接交给有文件访问权限的 Codex，按卡片指南导入。查看历史题组使用 `show --date YYYY-MM-DD`，重建旧界面使用 `session --date YYYY-MM-DD`。`--root` 指定另一份已经授权的学习目录，`--state-dir` 指定独立复习状态位置；默认保持与知识目录一起备份。

`check` 检查本地链接、wikilink 章节、资料类型与来源属性，属性只读取简单标量字段。远程网页和知识结论需要另行核对。`audit` 检查卡片结构与来源指纹，来源变化会列入 `needs_review`；读完变化并核对卡片后，再更新指纹与版本。

## 少量设置

.secondbrain.json 可设置 timezone、daily_limit、new_limit、concept_limit、interval_days 与 source_dirs。每日上限 1–25，新卡上限可以为 0。修改设置只影响后续选卡；历史快照保留原内容。

source_dirs 是正式知识的顶层目录列表。新增一种来源时，增加目录及对应指南，再加入此列表。书籍与实践记录见 [其他来源](其他来源.md)。工具递归读取其下的 Markdown，检查来源属性，初始化时也会带上这些目录。待学概念与 Flashcards 不可加入制卡来源。

目录层次可以按领域调整；精确标题是卡片的定位依据，修改后需维护链接和卡片版本。

## 按需扩展

网页、字幕、论文等读取工具见[来源与工具](来源与工具.md)，也可以沿用你已有的工具或直接提供文本。定期整理对话、回顾概念和维护公开仓库的做法见[自动整理与维护](自动整理与维护.md)。

复习使用三档固定间隔。若以后接入 FSRS 等排程算法，需保留卡片编号、内容版本、明确反馈和历史题组，并验证评分映射与排程变化。

## 检查代码改动

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s .flashcards -p 'test_*.py'
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tools -p 'test_*.py'
```

测试使用通用示例与独立临时目录。修改界面后，在普通浏览器检查翻面、展开、来源、反馈导出、重新打开与窄屏。
