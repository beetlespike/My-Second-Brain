# 工具与扩展

需要 Python 3.9 或以上。核心工具使用标准库，随附 KaTeX 离线渲染公式，无须运行服务器、配置 API 密钥或安装 Obsidian 插件。所有命令从学习目录运行。Windows 可以将 `python3` 换为 `py -3`；系统缺少时区数据时，在项目虚拟环境安装 `tzdata`。

## 常用命令

在已有项目旁边创建空白学习目录：

```sh
python3 tools/workflow.py init ../My-Learning --empty
```

省略 `--empty` 会带上当前示例知识。初始化只写入空目录，保留已有内容；配置过的来源目录随知识一起复制，个人复习记录、缓存、Obsidian 设置与 Git 历史不会带入。

检查与复习：

```sh
python3 tools/workflow.py check
python3 .flashcards/review.py audit
python3 .flashcards/review.py scan
python3 .flashcards/review.py session
python3 .flashcards/review.py feedback --input '下载的反馈.json'
```

反馈也可以直接交给有文件访问权限的 Codex，按卡片指南导入。查看历史题组使用 `show --date YYYY-MM-DD`，重建旧界面使用 `session --date YYYY-MM-DD`。`--root` 指定另一份已经授权的学习目录，`--state-dir` 指定独立复习状态位置；默认保持与知识目录一起备份。

check 检查本地 Markdown 与 wikilink 的目标、wikilink 章节、资料类型与来源属性；不核验远程网页和知识结论。属性检查只读取简单标量字段。audit 检查卡片结构与来源指纹。来源已变化的卡片列在 needs_review，不应直接刷新指纹掩盖变化。

## 少量设置

.secondbrain.json 可设置 timezone、daily_limit、new_limit、concept_limit、interval_days 与 source_dirs。每日上限 1–25，新卡上限可以为 0。修改设置只影响后续选卡；历史快照保留原内容。

source_dirs 是正式知识的顶层目录列表。新增一种来源时，增加目录及对应指南，再加入此列表。书籍与实践记录见 [其他来源](其他来源.md)。工具递归读取其下的 Markdown，检查来源属性，初始化时也会带上这些目录。待学概念与 Flashcards 不可加入制卡来源。

正文与来源信息保持可读。目录层次可以按领域调整；精确标题是卡片的定位依据，修改后需维护链接和卡片版本。复杂知识图谱、向量检索和额外数据库不属于当前运行要求。

## 按自己的节奏安排

先手动使用 Prompts 中的整理、回顾与复习提示。想定时运行时，再由本人确认频率、读取范围、写入边界及费用，并在自己可用的自动化工具中设置。可以参考个人实践中的每日复习与每三日回顾；这只是可选节奏。

回顾记录可放在 .local/maintenance.md，保存每个来源实际读到和处理到的位置、尚缺的前文或图片、对应页面与下一步。中断后从实际位置继续，不以运行日期代替内容覆盖。定时触发、生成题组和用户实际收到界面分别核对。

## 扩展实现

文章抓取、论文解析和音频转写可以采用现成工具，输出文本和来源锚点后沿用笔记流程。当前未捆绑这些依赖，也不自动下载模型。是否向外部服务发送内容由用户决定。

复习仍沿用原有的三档固定间隔。若以后接入 FSRS，应保留卡片编号、内容版本、明确反馈和历史题组，单独验证评分映射与排程变化。

## 检查代码改动

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s .flashcards -p 'test_*.py'
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tools -p 'test_*.py'
```

测试使用通用示例与独立临时目录。修改界面后还需在普通浏览器检查翻面、展开、来源、反馈导出、重新打开与窄屏。浏览器界面离线可用；首次安装 Python 等运行环境仍按其各自安装方式处理。
