# 标准误

对同一个总体重复取大小相同的样本，每次都会得到一个估计值。标准误描述这些估计值的波动，等于估计量抽样分布的标准差。

## 定义与条件

设 X_1,...,X_n 相互独立、同分布，方差为有限的 σ²。对[[Concepts/数理基础/Sample Mean|样本均值]]，有：

$$\operatorname{Var}(\bar X)=\frac{1}{n^2}\operatorname{Var}\left(\sum_{i=1}^{n}X_i\right)=\frac{1}{n^2}\sum_{i=1}^{n}\sigma^2=\frac{\sigma^2}{n}.$$

第一步使用方差对常数缩放的平方关系，第二步使用独立性使交叉协方差为零。于是 $\operatorname{SE}(\bar X)=\sigma/\sqrt n$。独立性是这个推导的一项充分条件。

## 与观测值的标准差有什么区别

σ 描述单个观测值的波动，σ/√n 描述整批样本均值的波动。增大 n 可以降低后者，单个观测的分布仍保持原样。σ 未知时常用样本标准差 s 估计，得到 s/√n；这个估计值也受样本影响。

## 零一试验

若 X_i 为 Bernoulli(p)，则 σ²=p(1-p)。p=1/2、n=16 时，标准误为 sqrt((1/4)/16)=1/8。它不是这一批数据的绝对误差。
