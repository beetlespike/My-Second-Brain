# 模型怎样开始回答

**第一个输出是从哪一步来的？** 输入 a、b、c 时，模型在预填充阶段算完这三个位置，用 c 的输出选出 d。接下来的解码步骤把 d 送进去，用它预测 e。第一个输出在这两步之间就已经有了。[Prefill 与 Decode](../Concepts/推理系统/Prefill%20and%20Decode.md)

要算 e，每一层都用得上先前位置的键和值。把它们留下来，下一步就可以接着算。这些状态属于各自的请求，所以短请求结束后可以腾出位置，长请求仍能沿用自己的状态。前一半是缓存的作用，后一半是连续合批解决的调度问题。[KV 缓存](../Concepts/推理系统/KV%20Cache.md) · [连续合批](../Concepts/推理系统/Continuous%20Batching.md)
