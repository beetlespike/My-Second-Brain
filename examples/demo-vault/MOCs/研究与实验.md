# 一个改动是否有效，怎样拿到证据？

看到分数变好时，需要知道是什么改变带来的，以及这个判断能推广到哪里。这里的算例均为教学构造。

从[可检验的问题](../Concepts/研究方法/Testable%20Questions.md)开始：让两种解释对同一道题给出不同预测。[近似反例](../Concepts/研究方法/Near%20Miss%20Examples.md)进一步说明怎样用只差一项条件的例子划清边界。

要检查一个系统组件的作用，读[消融实验](../Concepts/研究方法/Ablation%20Studies.md)；要比较两个方法在一批输入上的效果，读[配对评测](../Concepts/研究方法/Paired%20Evaluation.md)。前者关心改变了什么，后者保留每道题的成对结果。两种做法可以同时使用。

配对结果会自然接回[样本均值](../Concepts/数理基础/Sample%20Mean.md)和[标准误](../Concepts/数理基础/Standard%20Error.md)。输入彼此相关时，误差计算还需重新检查，可从[相关抽样](../待学概念/数理基础/Correlated%20Sampling.md)继续。
