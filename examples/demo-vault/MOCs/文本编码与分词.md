# 文字怎样变成模型能读的数字？

沿 `你 A👋` 这段文本追踪一次输入：字符先变成字节，分词器再把片段变成 token ID。模型生成 ID 后，还需要按同一套规则恢复文本。

1. [分词](../Concepts/计算机基础/Tokenization.md)先解释字符、字节、token 与 ID 各是什么。
2. [UTF-8变长编码](../Concepts/计算机基础/UTF-8%20Encoding.md)算出 `你` 为什么占三个字节。
3. [字节级BPE](../Concepts/计算机基础/Byte-Level%20BPE.md)用 `ab`、`bc` 的小例子解释怎样学习和使用合并规则。
4. [可逆解码](../Concepts/计算机基础/Reversible%20Decoding.md)说明为什么要先拼字节，再还原文字。

读完后可以自己回答：一枚 token 是否一定是一个完整的字？原文能够还原，是否意味着任意一串 ID 也能原样往返？

分词还影响评测单位。同一段文字切成不同数量的 token 后，逐 token 的[困惑度](../Concepts/信息论/Perplexity.md)不能直接拿来比较。这个连接把编码问题带到了[信息与预测](信息与预测.md)。
