# 待学概念

- [ ] [相关抽样](数理基础/Correlated%20Sampling.md)。推导标准误如何随样本量变化时，独立性消去了协方差项。估计配对评测的不确定性时，也要看各道题是否独立。重复记录或相关题目会怎样改变误差？
- [ ] [检索上下文预算](智能体与检索/Retrieval%20Context%20Budget.md)。检索与重排给出候选片段，prefill 要处理选中的输入，RAG 的回答需要关键证据。输入空间有限时，该留哪几段？
- [ ] [延迟预算下比较 RAG](模型评测/Latency-Constrained%20RAG%20Evaluation.md)。多给模型两段证据可能提高通过率，也会增加读入的时间。给定等待上限，试选一套方案。
