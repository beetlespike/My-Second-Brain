# 检索上下文预算

[检索与重排](../../Concepts/智能体与检索/检索与重排.md)决定哪些证据有机会进入提示词。[Prefill 与 Decode](../../Concepts/推理系统/Prefill与Decode.md)说明这些证据进了提示词就要占用输入预算。AI 从两篇笔记提出一个问题：上下文有限时，怎样保留足够的证据？

## 一道有预算的题

假设这一请求最多容纳 4096 个 token。说明与问题占 600，另外给输出留 500，资料一共能占 2996。手上有四个候选片段，每份分别占 1500、1000、900、700 个 token。第一份给结论，第二份给实验条件，第三份与第一份重复，第四份包含一个例外。怎样选能同时保留结论、条件和例外？

1500、1000、700 加起来要 3200，超过预算 204。可以检查哪部分可从原片段中裁掉，或者重新检索更短、仍指向原文的证据。若把包含例外的片段整个丢掉，生成时容易一句话把结果说得太宽。

这组数字是合成例子。真实系统还要计入提示模板和引用标记的长度。可以让 Codex 出一道换预算的变式，再回到 [RAG](../../Concepts/智能体与检索/RAG.md)。
