# Discover Missing Nodes from Existing Concepts

[简体中文](回顾与补学.md)

Follow `AGENTS.md` and `Guides/Network-Notes.md`. Starting from a cluster of concepts the user already studied, open questions left inside a topic map (`MOCs/`), or selected card feedback, find unrecorded bridging concepts that genuinely connect multiple existing notes. State clearly which existing nodes each candidate connects, why each link holds, and what concrete question understanding it answers.

Deduplicate by meaning and aliases before creating files: when an idea already exists in `Concepts/` or the study queue, enrich explanations and relative links there instead. Write genuine new discoveries as self-contained study notes under `Study-Queue/` (or `待学概念/` in Chinese vaults) with clear definitions, conditions, a worked example the learner can check by hand, and standard relative links back to existing concepts. When ready to surface alongside daily review, add a `## Study Card` section (`## 知识卡` in Chinese vaults) with front question and short answer.

If organizing source material in the same turn, follow [Organize studied material](intake.md) only for what the user actually covered, connect extracted concepts into the network and topic maps, and verify all links and affected flashcard sources afterward.

You may tag proposed study nodes with `ai-suggested` so graph tools that filter by tags (such as Obsidian) can highlight suggested explorations distinctly from learned notes.
