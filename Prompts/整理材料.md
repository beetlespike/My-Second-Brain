# 整理学过的材料

[English](intake.md)

我在这个学习库的聊天里只贴一个网址或文件时，请直接整理。先运行 `python3 tools/intake.py <链接或文件>`，打开返回的 `material`。从实际读到的材料提炼概念。我主动给的时间段、章节或想法优先。

返回 `needs_network` 表示当前终端无法联网。当运行环境支持联网审批时，请按宿主权限仅针对这一份公开材料重新执行原读取命令并重试。若返回 `partial`，说明读到的部分，并查找能补全它的来源。若返回 `needs_material`，先试已授权浏览器里的原网页、同一集的发布方字幕或已有论文解析，用 `--from` 接回。仍缺正文时，告诉我最少需要补什么。字幕、画面和讲义分别注明。

按含义和别名查已有节点。已有同义概念，就把这份材料补充的解释、例子或适用条件写进原页。新概念各写成能独立读懂的一页。资料页简要记下出处，链接到这次学到的各个概念。

把材料里的概念同库里已有的概念放在一起读。哪一步用到了一个熟悉的方法？哪个旧结论会随新条件改变？把理由写进正文，直接在那句话上加标准相对路径 Markdown 链接（`[概念名](相对路径)`）。例如，“要比较两种重排方法，可以固定候选段落，让它们处理同一批问题，逐题做配对评测”，这里就把“配对评测”链接到已有概念。能说明关系才连。

所有 Markdown 编辑器都能顺着标准相对路径链接直接打开目标页，Obsidian 等图谱工具也能据此画出这条关系边。从旧页读过来也需要这个例子时，把新理解补回旧页。几个概念能一起回答一个问题时，在相应的主题地图（MOC）里串起这段解释。现有地图容不下这个问题时再新建。不同地图可以引用同一个概念。

保留我的手写内容和纠正，核对链接与受影响的卡片。如果几个已有节点放在一起还缺一层解释，按 [发现新节点](回顾与补学.md) 评估是否值得记为待学。完成后给我看整理出了哪些概念、它们怎样接回旧节点，以及哪部分原文还有缺口。发链接本身不记为我已掌握。
