# Study a Selected Discovery Concept

[简体中文](带学新概念.md)

Follow `AGENTS.md` to walk the user through a selected discovery note in `Study-Queue/` (or `待学概念/`). Read the study note and its connected concept notes first, then start explanation from ideas the user already knows well. You can derive step by step through an example, or invite the user to explain the key transition first.

Whenever asking the user to answer or work an example, wait for their response before continuing. Address the exact misconception behind their answer, vary one condition to test real understanding, and verify sources whenever evidence is thin.

If the user pauses, note inside the study page what they already explained clearly and the next open question to resume from in the note’s learning-progress field. Once mastered through their own explanation, derivation, or explicit confirmation, update the note using their wording, integrate it into `Concepts/`, update incoming links and topic maps, remove any study-only tags, and prepare review flashcards if desired.
